Vos fichiers sont analysés dans votre navigateur. Rien n'est envoyé sur Internet, et le texte de vos conversations n'est pas conservé.

Comment obtenir mon export ?
  • ChatGPT : Paramètres → Gestion des données → Exporter les données. Un lien de téléchargement arrive par e-mail.
  • Claude : Paramètres → Confidentialité → Exporter les données, sur le web ou dans l'appli pour ordinateur (pas sur mobile). Un lien de téléchargement arrive par e-mail ; il expire au bout de 24 heures.

Pas de bouton « Exporter les données » dans Claude ? Avec un compte d'organisation (Team ou Enterprise), l'export doit d'abord être autorisé par un propriétaire de l'organisation. Sans cela, seuls Claude Code et Claude Cowork peuvent être mesurés.

Un nouvel import remplace le précédent pour le même service.

Hypothèses de calcul

Les fournisseurs publient peu de chiffres : tout ce qui est affiché ici est une estimation d'ordre de grandeur. Le nombre de tokens est estimé à partir de la longueur du texte (environ 4 caractères par token), puis converti en énergie selon la catégorie du modèle. Pour Claude Code, les nombres de tokens sont mesurés et non estimés ; la conversion en énergie reste une estimation. Le paramètre le plus incertain est le poids des tokens relus du cache : ils représentent l'essentiel du volume de Claude Code, et aucun chiffre public ne dit ce qu'ils consomment.

Repères publics : OpenAI a indiqué environ 0,34 Wh pour une requête ChatGPT moyenne (juin 2025) ; Google, 0,24 Wh pour une requête texte Gemini médiane (août 2025). L'intensité carbone dépend du pays du centre de données : environ 400 g CO₂e/kWh en moyenne mondiale, bien moins en France.
